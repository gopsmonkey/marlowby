Every outside resource used to build this site, following the competition’s copyright, fair use and AI usage rules.

  • About this site

    Marlowby is a fictional company. This site is a concept made for a student web design competition. The test-box quotes, makers, products and vote counts are illustrative, not real people or businesses.

  • Logo

    The Marlowby logo was designed by our team. The SVG version on this site was redrawn from it.

  • 3D scenes and product images

    The falling box, the shelf room and the box photos are drawn live in the browser with code written for this project. No stock photos, 3D models or third-party images are used. The U.S. map outline is a simplified shape plotted from public latitude and longitude points.

  • Design reference

    The layout style (rounded color blocks, floating menu, a product dropping into a scene on scroll) was inspired by the Bella Kitchenware website. No text, images, code or branding from that site were copied.

  • Shop layout research

    General shop patterns (a trust ticker, a shrinking menu bar, product tags on photos, a carousel with a progress bar) were studied on Mobbin screenshots of the Hims, Graza, Oura and Seed websites, and on the Graza, Olipop and Omsom websites. Only general layout ideas were used. No text, images, code or branding from those sites were copied.

  • Fonts

    Nunito by Vernon Adams, Figtree by Erik Kennedy, Instrument Serif by Rodrigo Fuenzalida and Jordan Egstad, and DM Mono by Colophon Foundry, all under the SIL Open Font License, served by Google Fonts.

  • Code libraries

    three.js r128 (MIT License) for 3D, GSAP 3.12 with ScrollTrigger (GreenSock standard no-charge license) for scroll animation, and Lenis 1.1 (MIT License) for smooth scrolling. Everything else is hand-written HTML, CSS and JavaScript.
