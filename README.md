# Marlowby

Concept website for **Marlowby**, a monthly subscription box of local products, small businesses and experiences from a different U.S. city each month. Built for a student web design competition.

## Pages
`index.html` (home), `how-it-works.html`, `plans.html`, `cities.html`, `about.html`, `faq.html`, `join.html`, `credits.html`

## Run it locally
It's a static site with no build step needed to view it:

```bash
python3 -m http.server 8743
```

Then open http://localhost:8743. Opening the files directly also works, but the 3D scenes load best from a server.

## Editing
The HTML pages are generated by `tools/build.py`. Edit the page content there, then rebuild:

```bash
python3 tools/build.py .
```

- `css/styles.css`: design system (colors, tiles, header, forms, footer)
- `css/home.css`, `css/pages.css`: home page and Cities/About page styles
- `css/type.css`: font roles
- `js/scene.js`: three.js scenes (balloon box drop, shelf room, rendered box photos)
- `js/main.js`: menu, scroll motion, carousel, map, quiz, forms
- `DESIGN.md`: design rules, motion specs and sources of inspiration

Sources, licenses and the AI usage citation are on `credits.html`.
